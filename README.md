# HomeCrew

Android household chore planner, currently in the **1-A design-system** phase.

## Development workflow

- Android source, tests, build workflows, and code review live in this GitHub repository.
- Design documents and reference boards are stored in [HomeCrew Google Drive](https://drive.google.com/drive/folders/16xQAcSuTapJ-D8sUdJBUJvfCtBIdo_Tx).
- Start with a local-only Compose UI; Firebase authentication, household invitations, and cross-device synchronization are intentionally deferred.
- Use a feature branch and pull request for each implementation stage; do not commit signing keys or credentials.

## Current milestone

1-A — Shared monochrome design system: theme tokens, typography, reusable Compose components, preview gallery, and build validation.

**Design reference:** [1-A visual board](https://drive.google.com/file/d/1Hr627UN6f-MJb2iDjO_3-5rByqs5IfKa/view?usp=drivesdk).

The application module will be added in the 1-A feature branch.
