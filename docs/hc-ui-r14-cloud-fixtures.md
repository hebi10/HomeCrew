# HC-UI-R14-B — 누락 공동 공간 화면 계측 보강
기준: P01~P27 명세 v1.2 및 #75 병합 main 85ebf598fa7b7508f8ab3d4b36a85838cd22356e. P17/P18의 기존 FakeGateway 검증은 #74에서 성공했으나 P20 소유자 메뉴는 실제 공동 일정 화면이 아니다.

## 추가
- P19: 소유자/일반 구성원 목록과 소유권 이전 확인 취소.
- P20: 공동 집안일 실제 컴포넌트에 합성 작업 표시, 오프라인 시 캐시 내용 미노출.
- P21: 실제 공동 집안일 화면에서 자료 이전 페이지 진입, 대상에 작업이 있으면 읽기 차단, 빈 대상에서 읽기 버튼 활성화, 뒤로 이동. 로컬 데이터 읽기·복사 자체는 수행하지 않는다.
- P22: 부분 반영/조회 잠김 상태·진행률 표시, 복구 확인 취소.
- P25: 계정 삭제 사전 확인의 성공·서버 오류 상태. 실제 삭제 기능을 실행하지 않는다.
- ReadOnly FakeGateway로 모든 쓰기 호출을 거부하고 호출 수 0 검증. 실제 Compose 화면 캡처를 screen-qa-fake-gateway로 분리, manifest는 fixture_only로 분류. 모든 기존 서버/계정/권한 게이트 및 Play 정책 유지.
- API35 선별 계측(1개 환경) 및 기존 Android CI의 Python 분류 테스트. 최종 5환경 전체 QA는 모든 선행 작업과 승인된 정확한 main에서 기존 수동 흐름으로 1회 실행한다.

## 제한
이 PR의 추가 검증은 테스트용 합성 데이터 화면에 한정한다. 비운영 Firebase 실로그인·서버 권한·자료 이전 전 과정, P01~P27 최신 최종 main 전체 캡처 및 시안 대조는 미완료이다. 운영 Firebase 및 Play를 변경하지 않는다.

## 재검증 보완 (2026-11-25)
- 41329a4의 Android CI 성공, API35 추가 계측 실패(45553283877). XML 보고서에서 P21 로컬 자료 읽기 비활성 검사 assertFalse(223행) 실패를 확인. P19 3종과 P20 공동 집안일 PNG는 확보되었으나 실행 전체가 실패했으므로 정상 검증으로 승격하지 않는다.
- 기존 버튼 내부 텍스트의 UIAutomator isEnabled 값 대신 실제 Compose의 병합된 버튼 semantics assertIsNotEnabled/assertIsEnabled를 사용한다. 기존 스냅샷이 있는 대상에서 차단되고 빈 대상에서 활성화된다는 두 조건을 그대로 검사하며 실패 시 PNG/XML 진단을 남긴다. 앱의 실제 이전·권한·백업 로직은 변경하지 않는다.
- 오프라인 전환 직전 합성 집안일을 다시 표시한 뒤 동일 비어 있지 않은 스냅샷을 stale로 바꾸고 Compose 트리에서 집안일이 없어졌는지 확인한다. 모든 변경 호출 0 검증은 유지한다.

## 3차 계측 동기화 보완
- 2a0d052의 Android CI 성공, 계측 45556058289 실패. 실패 XML에서 앱의 초기 ProgressBar만 남고 공동 구성원 화면이 아직 구성되지 않은 상태를 확인했다. 이전 수정에서 Compose 테스트 규칙은 도입했지만 첫 화면 및 대부분의 화면 전환은 UIAutomator의 실시간 대기만 사용해 Compose 테스트 프레임/코루틴 동기화가 누락되었다.
- 전체 추가 화면 계측을 Compose semantics 대기·스크롤·클릭 및 waitForIdle로 통일한다. 가상 화면 변경은 runOnIdle에서 적용하고 첫 화면 구성도 Compose 규칙으로 동기화한다. UiDevice는 PNG/XML 증거 수집과 기존 에뮬레이터 ANR 처리에만 사용한다.
- 실제 버튼의 활성/비활성 검증, 전체 트리에서 권한 없는 메뉴·오프라인 집안일이 없는지 검사, 복구/소유권 이전 확인 취소, 모든 쓰기 요청 0 검증과 기존 11종 화면 시나리오를 유지한다. 실패 시 원래 오류를 보존하며 진단 파일을 수집한다. 운영 앱 코드/서버/Play 변경 없음.
