# HomeCrew UI-R09 — 전체 화면·기능 통합 QA

기준선: `main` UI-R07 병합 `bfd8cc4639f32a1a2e4cb3986d71b6a3ece2c214`. UI-R08 PR #24는 별도 자동 검증·병합 진행 중. 이 브랜치는 QA 워크플로만 추가하며 앱 기능, Room 스키마, Play 서명과 릴리스 설정은 변경하지 않는다.

## 자동 검증
- `ui-r09-device-matrix.yml`의 Android API 29/35/36 일반 휴대전화, API35 160% 글꼴, API35 태블릿 프로필에서 기존 전체 connectedDebugAndroidTest 및 실제 화면 PNG 실행.
- 성공 판정은 각 matrix job `success`, Gradle 계측 실패 0건, 각 환경에서 7장 이상 실제 PNG와 테스트 리포트 확인.
- 일반 Android CI의 JVM/Lint/debug/androidTest 빌드 및 기존 화면 QA API35도 확인.
- 기존 테스트에는 온보딩, 홈, 월·주·일 일정, 필터, 등록/반복/담당, 상세·완료·취소, 통계, Room 영속 저장·재시작이 포함된다.
- UI-R08 병합 후 설정 변경·새 구성원·기본 구성원·테마·재시작 검증을 반드시 최신 main에서 재실행한다.

## 범위 및 미검증 항목
- 이 변경만으로 폴더블 힌지, 실제 물리 기기, Android 200% 폰트, 회전 및 멀티윈도우, 다양한 DPI/360dp 기기, Play Console 테스터 설치를 통과한 것으로 취급하지 않는다.
- `pixel_tablet` AVD 프로필이 러너에서 지원되지 않거나 29/36 system image가 설치되지 않으면 기기 환경 설정 오류와 앱 실패를 구분하여 수정·재검증한다.
- 실제 PNG에서 색상, 화면 잘림, 터치 목표, 간격, 스크롤, 시스템 인셋, 1명·3명 구성원과 빈 데이터 상태는 사람의 시각 검수가 필요하다.
- 현재 Room은 단일 기기 로컬 저장이므로 Firebase 공유 기능 테스트는 별도 후속 작업.
- 구형 PR #12의 백업/건너뛰기 기능은 병합 확인 전 출시 검증에 포함하지 않는다.

## 종료 게이트
1. UI-R08 PR #24 최신 HEAD의 API35 설정 저장·앱 재시작 QA 성공, 안전 병합 확인.
2. 병합된 최신 main에서 API29/35/36 및 태블릿·160% 글자 매트릭스 재실행 및 화면 검수.
3. 이 QA PR이 모든 체크 통과한 경우에만 병합; main 통합 CI/API35 재실행.
4. 스토어 이미지 ASSET-03~04는 최종 main 실화면만 사용. 비공개 테스트와 Play 심사·테스터 설치 여부는 각각 별도로 확인한다.
