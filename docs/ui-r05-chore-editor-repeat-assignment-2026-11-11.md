# UI-R05 — 집안일 등록·반복·담당 방식 개선

## 핵심 원칙
- 기존 Kotlin/Jetpack Compose 구조, 기존 Room DB/Repository/ViewModel, 반복 계산/분담/저장 및 4탭 내비게이션을 그대로 유지합니다.
- 디자인은 라이트 화이트·중성 회색, 다크 차콜·블랙, 최소한의 라운드와 기존 20dp 화면 여백/52dp 버튼/48dp 터치 영역을 유지합니다.
- PR #12의 날짜 자동 갱신·건너뛰기·로컬 JSON 백업/복원은 미병합이므로 이번 PR에 포함하지 않습니다.

## 구현
1. 등록 폼(HC-08)
  - 본문 공통 세로 간격을 20dp에서 16dp로 정리합니다.
  - 카테고리 선택 영역에 '좌우로 밀어 선택' 힌트를 추가합니다.
  - 1~5점 업무량 칩도 좁은 화면에서 가로 스크롤 가능하게 합니다.
  - 사용자 흐름을 입력(이름→카테고리→설명→업무량)→담당 방식→반복→시작일·시간→예정 일정 미리보기 순서로 정리합니다.
  - 향후 예정 미리보기는 기존 저장에서 사용하는 previewDraftInstances와 동일한 62일 회차 생성 범위를 사용합니다. 최대 3건의 날짜·시간·담당자를 표시합니다.
  - 반복 안 함/반복 선택 시 제목을 구분하고, 62일 바깥의 예정은 생성되지 않았음을 분명하게 안내합니다.

2. 반복 설정(HC-09)
  - 6종 빈도를 48dp 이상으로 터치 가능한 전체 행 선택 형식으로 통일해 라디오 단독·텍스트 선택의 차이를 없앱니다.
  - 주/격주 모드 진입 시 요일 미선택 상태라면 시작일의 요일을 기본 선택하도록 통일합니다.
  - 반복 없음 모드는 '예정 일정'으로, 반복 모드는 '다가오는 일정 · 최대 3회'로 표현합니다.
  - 반복 날짜는 startDate부터 today+62일까지 실제 저장 생성 범위에 맞춰 계산하며, 29·30·31일 및 윤년 월말 보정 안내는 유지합니다.
  - 잘못된 주간 요일 선택 시 기존 오류 및 작성값 보존을 유지합니다.

3. 담당 방식(HC-10)
  - 고정 담당·순번제·업무량 균형 3종 선택 행을 동일한 접근성·48dp 터치 형식으로 통일합니다.
  - 순번제는 멤버 칩/체크 순서가 아니라 등록된 구성원 표시 순서로 배정된다는 것을 텍스트로 보여줍니다.
  - 업무량 균형은 기준 구성원별 업무량 점수를 표시합니다.
  - 고정 담당 전환 때 현재 선택 중인 유효 구성원을 기본으로 1명 선택해 인덱스 오류를 막습니다.
  - 가장 중요한 후속 3회 배정 미리보기는 임의 3회 계산을 쓰지 않고 실제 회차 발생 날짜와 동일한 previewDraftInstances를 사용해 날짜·배정자와 동기화합니다.
  - 0명일 때 오류를 유지하고 예고 회차가 없으면 그 이유를 안내합니다.
