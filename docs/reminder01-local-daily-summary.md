# REMINDER-01 — 로컬 집안일 요약 알림

## 구현
- Android 13+ 알림 권한을 사용자가 설정에서 명시적으로 허용할 때만 알림 활성화.
- 기본 알림은 OFF, 시간 20:00. HH:mm(24시간제) 유효성 검사, 로컬 SharedPreferences 영속화.
- WorkManager 2.12.0의 고유 일별 작업(24h 주기)을 사용자 선택 시간 이후 실행. 즉시/정확한 알람이 아니라 시스템 배터리·작업 제약에 따라 지연될 수 있습니다.
- 매회 Room DB의 **실제 오늘 회차**만 확인하고 완료/건너뜀 제외, 남은 건수가 0이면 푸시하지 않음.
- 하루 중복 알림 방지, 비활성화 시 예약 작업·기존 알림 취소, 탭하면 HomeCrew 실행.
- 앱 시작 시 이전 설정으로 일정 재등록(시간대 변경 및 재시작 포함). 인터넷·Firebase/FCM과 독립.

## 운영·QA
- Android CI/단위 테스트, API29/35/36·태블릿/큰 글꼴·다크 모드·알림 허용/거부 계측 검증 필요.
- 기기 제조사 절전 정책·알림 채널 차단 상태 실기기 확인 필요.
- 개인별 집안일 알림, 공동 집 초대/담당 변경 FCM은 FIREBASE-05 완성 후 REMINDER-02 별도 작업.
- 사용자가 승인하지 않은 Google Play 업로드·Firebase/Pages 게시 없음.

## 2026-11-17 QA 보완
- WorkManager의 `UPDATE`는 기존 예약 기준 시점을 유지하므로, 알림 시간 수정 시 의도치 않게 이전 시각에 알림이 울릴 수 있습니다. `CANCEL_AND_REENQUEUE`로 재계산한 다음 실행 지연을 다시 적용합니다.
- 백그라운드 Worker가 오늘 회차를 집계하기 전에 `HomeCrewRoomRepository.extendUpcoming(today)`를 호출하여, 62일 이상 앱을 열지 않았더라도 반복 집안일 알림이 누락되지 않도록 합니다.

### 재진입 예약 보호
- 앱 시작 시는 `ExistingPeriodicWorkPolicy.KEEP`로 이미 예약된 오늘의 작업을 유지합니다. 앱을 열었다는 이유만으로 지연 중인 알림을 취소하지 않습니다.
- 사용자가 알림을 켜거나 시각을 저장할 때만 `CANCEL_AND_REENQUEUE`로 새 시작 시각에 재고정합니다. 알림을 끄면 기존 작업·알림을 취소합니다.
