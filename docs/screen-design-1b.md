# HomeCrew · 1-B 메인 화면 설계 및 Compose 구현

> 상태: 4개 메인 화면을 Jetpack Compose로 구현한 **로컬 시연 버전**입니다. 실제 사용자 집안일 데이터 저장은 다음 단계에서 연결합니다.

시안 PNG는 **개념 디자인**이며 실제 Compose 캡처가 아닙니다. 이미지에 포함된 GitHub 상태·CI 설명은 디자인 장식일 뿐, 검증 근거로 사용하지 않습니다. 검증 여부는 해당 커밋의 Actions 결과로 확인해야 합니다.

1-A의 블랙·그레이 색상/서체/간격/컴포넌트를 유지하고 완료·기한 경고에는 의미 색상만 사용합니다. 과도한 장식·그라데이션·불필요한 애니메이션을 사용하지 않습니다.

## 구현 범위

| 화면 | 파일 | 핵심 UI | 실제 동작 |
|---|---|---|---|
| 홈 | `HomeCrewHomeScreen.kt` | 오늘 진행률, 현재 구성원, 내 할 일, 다른 구성원 | 구성원 전환, 완료 체크·취소, 테마 변경, 1-A 갤러리 열기 |
| 일정 | `HomeCrewScheduleScreen.kt` | 월/주/일 전환, 기간 이전/다음, 날짜 선택, 당일 작업 | 날짜 이동, 오늘 복귀, 해당 회차 완료 체크 |
| 집안일 | `HomeCrewChoresScreen.kt` | 검색, 카테고리 필터, 당일 상태 필터, 반복 작업 원본 목록 | 필터 및 검색, 집안일 정보 보기 |
| 통계 | `HomeCrewStatsScreen.kt` | 주/월 기간, 완료율, 완료 수, 배정·완료 난이도, 주간 막대, 구성원 비교 | 데모 완료 상태 변경 즉시 재집계 |

4개 화면은 기존 `HomeCrewBottomBar`로 연결되며 선택 상태 및 탭별 사용자 필터 상태를 보존합니다. 화면은 스크롤 가능하고, 빈 결과·경고·예정·완료 상태를 표기합니다.

## 데이터와 상태

- `DemoChoreViewModel`: 동일 세션에서 공유되는 비영속 예시 작업 7종과 29일치 회차.
- `DemoChore.kt`: 집안일 원본, 회차, 날짜별·주별·월별 필터, 완료율과 난이도 집계.
- 예시 데이터는 기기 로컬 메모리에서만 동작하며 클라우드 공유·DB 저장이 없습니다.
- 완료를 누르면 홈/일정/통계가 같은 ViewModel 상태를 구독하여 즉시 반영됩니다.
- 실제 집안일 추가·수정·삭제 버튼은 저장 성공처럼 동작하지 않고 후속 구현 안내를 표시합니다.
- 실제 자동 배정과 반복 생성 엔진도 아직 없습니다. 예시 반복 문자열은 시연용입니다.

## 디자인 디테일

### HC-05 홈
상단 공간 이름/오늘 날짜, 테마·디자인 시스템 접근, 현재 보기 구성원 칩, 전체 완료율 카드, 내 할 일, 다른 구성원 할 일, 추가 버튼. 완료 항목은 취소 가능하고 줄 긋기/상태 아이콘으로 구분합니다.

### HC-06 일정
기본 주 모드, 월 달력·주간 스트립·일간 세 모드 전환. 기간 이전/다음, 날짜 터치, 오늘 복귀. 선택한 날짜의 예정/완료/기한 초과를 작업 행에 표시합니다. 월 그리드는 월요일부터 시작합니다.

### HC-07 집안일
제목 검색, 카테고리 칩, 상태 칩, 결과 건수 및 반복 작업 카드. **원본 목록**의 상태 표시는 오늘 회차 기준임을 명시하고 미래·과거 회차와 혼동하지 않게 합니다. 상세는 읽기 전용 대화상자입니다.

### HC-12 통계
주/월 집계와 그래프. 완료율 = 완료 회차 / 대상 회차. 배정 업무량과 완료 업무량은 서로 별개이며, 구성원별 비교는 배정 점수 기준입니다. 주간 막대는 선택한 월간 모드에서도 '주간 완료 추이'로 제목을 명시합니다.
