# HomeCrew · 1-C 온보딩·집·구성원·템플릿

> 목표: 로컬 MVP의 HC-01~HC-04 초기 설정 Compose 흐름을 제공하고, 선택값을 홈·집안일·통계의 시연 상태에 반영합니다.

## 화면

| 화면 | 역할 | 주요 동작 |
|---|---|---|
| HC-01 시작 | 로컬 관리 안내 | 핵심 기능 3종·시작 버튼·기기 내 데이터 안내 |
| HC-02 우리 집 만들기 | 공간 이름 | 기본값 우리 집, 공백/20자 초과 검증 |
| HC-03 구성원 등록 | 로컬 프로필 | 추가·수정·삭제, 이름 중복·12자 제한, 기본 구성원 선택, 1명 이상 |
| HC-04 템플릿 선택 | 기본 집안일 | 6개 카테고리 12종 체크, 0개 건너뛰기, 기본 4개 추천 |

## 동작 범위

1. 최초 실행 시 초기 설정을 진행합니다. 설정은 Android `SharedPreferences`에 **현재 기기만** 저장합니다.
2. 시작하기→집 이름→구성원→집안일 템플릿→홈 순서입니다. 이전 단계 복귀 시 입력은 유지합니다.
3. 홈의 이름과 구성원 선택, 집안일 탭의 항목 목록, 통계의 구성원 항목에 설정 결과가 반영됩니다.
4. 선택한 템플릿은 **오늘 1회씩의 임시 DemoChore**로 표시합니다. 집안일 반복 일정 자동 생성과 실제 완료 이력 저장은 구현하지 않았습니다.
5. 완료 체크는 실행 중 메모리에만 유지되고 앱 재시작 시 초기화됩니다. 집·구성원·템플릿 목록 설정만 기기에 남습니다.
6. 로그인, 초대, 가족 간 동기화, Firebase, Room, FCM, Google Play 배포 설정은 포함하지 않습니다.

## 코드

- `ui/setup/HouseholdSetup.kt`: 로컬 설정 모델·템플릿·입력 검증·시연 회차 매핑
- `ui/setup/LocalHouseholdStore.kt`: 로컬 기본 설정 저장·복원
- `ui/setup/HomeCrewSetupFlow.kt`: 4개 단계 Compose UI, 라이트·다크 Preview
- `MainActivity.kt`: 첫 실행에서 초기 설정 진입, 저장 후 메인 탭
- `HomeCrewMainScreens.kt`: 설정 기반 시연 상태 연결
