# UI-R02 — HomeCrew 홈 정보 우선순위·빠른 추가

기준: `main` 57a2286 (UI-R01 완료), Google Drive `011_HomeCrew_디자인시안_실제화면_차이분석_단계별개선계획_2026-11-11`

## 반영 범위
- 첫 화면 정보 우선순위: 집 이름·날짜·테마 전환 → 오늘 전체 진행률 → 구성원 선택 → 해당 구성원 집안일 → 다른 구성원 집안일.
- 집안일 추가 버튼을 페이지 최하단에서 '내가 할 일' 제목 옆으로 이동, 최소 48dp 클릭 영역 확보.
- 세로 간격 18dp → 12dp, 외곽 상하 패딩 24dp → 16dp. 집안일 목록의 행 터치 영역 64dp와 기존 공통 컴포넌트는 유지.
- 구성원이 1명일 때 '다른 구성원' 빈 섹션을 숨겨 불필요한 화면 공간 절약. 다인 구성원일 때는 기존 목록 유지.
- 빈 목록에 짧은 안내만 노출. 현재의 테마 전환 및 기존 4개 탭 유지.

## 보호 범위
- Room, ViewModel, 반복, 담당, 완료·취소, APK/AAB, Play 배포·서명·트랙, 공통 색상 토큰 변경 없음.
- 아직 없는 집·구성원 편집/설정 진입은 UI-R08에서 처리. 임시 버튼을 만들지 않음.
- PR #12(백업·건너뛰기)와의 충돌 방지를 위해 홈 UI와 계측 검사만 수정.
