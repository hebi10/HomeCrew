# HC-05-C — 로컬 구성원 수정 및 기록 보존

- 기존 로컬 이름 기반 식별 구조를 유지합니다. 이름 수정은 집 설정의 멤버/기본 구성원과 Room 정의 담당자, 배정 순서, 회차 담당자 및 완료 행위자를 일괄 변경합니다. ID, 시간, 업무량, 완료·건너뛰기 상태는 유지합니다.
- 다른 활성 구성원 또는 기존 기록의 이름과 중복되는 이름을 차단합니다. 마지막 구성원 또는 과거/현재 배정·완료 참조가 있는 구성원은 삭제하지 않습니다. 사용하지 않는 구성원만 삭제하고 기본 구성원은 남은 첫 사람으로 변경합니다.
- Room 트랜잭션 내에 참조 수정과 before/after 설정 복구 기록을 함께 커밋합니다. SharedPreferences를 확인 후 저장하고 같은 복구 기록만 제거합니다. 중간 종료/저장 실패 시 앱 시작에서 복구하며 복구 전 정상 화면을 잠급니다. 기존 로컬 저장/일정 보충/백업 쓰기 경로를 같은 mutex로 직렬화하고 미복구 상태의 추가 Room 변경을 차단합니다.
- UI에서 명시적 수정·삭제를 확인하며 새 참조 검증은 DB 안에서 수행합니다. 기존 데이터 백업 및 마이그레이션 조회와 연결합니다.
- Kotlin 계획 단위 테스트, 실제 Room 파일 재개방 및 실패한 설정 저장 복구 API35 계측, 기존 설정 저장·재시작 회귀를 추가합니다.
- 참조가 있는 구성원의 보관/비활성화 및 미래 담당 재설정 후 삭제 정책, 다중 프로세스 저장소 설계, 계정 데이터 삭제는 별도입니다. 실제 사용자 데이터, 운영 Firebase 및 Play 배포 변경 없음.
