# HC-04-B2 — 명시적 Android 이전·원본 백업·영수증 복구

- 서버 확인된 소유자 및 빈 공동 공간에서만 원본 자료 검사 후 사용자 확인 모달을 엽니다. 확인 시 Room과 설정을 다시 읽고 동일 digest와 300행/512KiB 제한을 검증합니다.
- 원본 JSON 백업을 생성하고 decode 결과와 비교한 뒤, 프로젝트·UID·공간별 noBackupFilesDir의 AtomicFile에 매핑·검증 식별자·원본 설정과 백업을 보존합니다. 디스크 저장/읽기 검증 실패는 전송 차단입니다.
- 명시적 요청으로만 importLocalHouseholdManifest를 호출합니다. 서버 receipt의 digest 및 전체/완료/건너뜀 수가 일치해야 완료 확인을 기록합니다. 원본 Room과 기존 로컬 설정은 수정·삭제하지 않습니다.
- 재진입에서는 저장된 요청을 보여 주고 getLocalHouseholdMigrationReceipt로 읽기 전용 확인을 제공합니다. 영수증이 없고 원본·대상·매핑이 그대로인 경우에만 사용자 확인 후 같은 digest로 재시도합니다. 새 이전으로 덮어쓰지 않습니다.
- 보존된 백업은 앱 삭제 시 없어질 수 있습니다. 기존 로컬 백업 기능으로 별도 외부 보관을 안내합니다. 자동 원본 복원이나 삭제를 수행하지 않습니다.
- API35 실제 AtomicFile 저장·재생성·계정 격리·영수증 확인과 demo Firebase 권한/receipt QA를 추가합니다. 대용량 분할 이전, 변경된 원본의 미확정 요청 취소 정책, 백업 보존/삭제 정책 및 실제 기기 이관·프로세스 강제 종료 검증은 후속입니다.
- 개발 미리보기만. 운영 Firebase/Google Play 배포 없음.
