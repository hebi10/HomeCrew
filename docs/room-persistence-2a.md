# HomeCrew · 2-A-01 Room 로컬 데이터 계층

## 목적 및 구현 범위
- 로컬 우선 MVP로 전환하기 위한 Room(SQLite) 데이터베이스 v1 및 DAO 구축.
- 기존 1-D Compose 화면은 그대로 유지하며, 현재 단계에서 데이터 저장을 UI에 연결하지 않습니다.
- Firebase, 로그인, 서버 동기화, Play 배포 설정은 수정하지 않습니다.

## 데이터 구조
1. chore_definitions: 집안일 원본, 업무량, 시간, 반복/담당 규칙, 등록·수정 시각.
2. chore_assignment_members: 집안일별 참여자와 표시 순서. 클릭 순서로 회차가 뒤바뀌지 않도록 position을 보존.
3. chore_occurrences: 일자별 담당자, 완료 여부, 완료 시각·완료자, 건너뛰기 상태·사유.
4. app_state: 초기 템플릿 적용 여부 등 로컬 부트스트랩 마커용.

## 트랜잭션 정책
- saveSchedule()은 원본·참여자·예정 회차 갱신을 단일 Room 트랜잭션에서 실행.
- 완료한 회차와 오늘 이전 회차는 수정 후에도 보존.
- 미래 미완료 회차만 삭제 후 재생성하여 이중 예약 방지.
- 원본 삭제 시 연관 담당·회차는 외래 키 CASCADE로 함께 제거.
- 완료 상태 저장은 개별 회차 ID를 기준으로 하며 중복 호출이 회차 개수를 증가시키지 않음.

## 기술 설정
- Kotlin 2.2.21, KSP 2.2.21-2.0.5, Room 2.8.5, minSdk 26 유지.
- 데이터베이스 파일: homecrew.db
- 초기 버전은 exportSchema=false. 첫 실제 배포 전 스키마 이력 파일을 생성·버전 관리하고 migration QA를 추가할 것.

## 검증
