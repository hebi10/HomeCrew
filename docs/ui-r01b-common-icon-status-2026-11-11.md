# UI-R01 추가 보정 — 공통 디자인·아이콘·상태 안내

기준: HomeCrew main `c62a5178fdbe9e5f4f255964149d490b6aeed1c1` / 2026-11-11
기존 완료 작업: UI-R01 PR #16(공통 색상·안내·개발 갤러리 정리)
이번 범위: UI-R01 후속 보정. 기존 PR과 Drive 문서를 덮어쓰지 않음.

## 확인한 사실
- 1-A 공통 디자인 시스템의 라이트/다크 색상과 타이포·간격·터치 토큰은 이미 구현. 유지한다.
- HomeCrewStatusChip은 상태명과 의미 색상은 있으나 아이콘이 없다.
- HomeCrewTaskRow는 예정/미완료가 선형, 완료만 채워진 아이콘이어서 일관성이 없다.
- 홈 테마 순환은 시스템·라이트·다크 3모드이나 아이콘은 항상 WbSunny로 동일하다.
- HomeCrewProgressCard는 0/0을 '0% 완료'로 표기하고 Material3 진행 바의 끝점을 노출할 수 있어 0건과 미완료 상태가 구별되지 않는다.
- 통계의 주간 완료 막대는 완료가 0건인 요일도 최소 3dp 검은 막대를 표시한다.
- 집안일 상세에 '기존 데모의 고정 담당' 문구가 남아 있고, 공통 오류 대화상자 제목이 모든 오류를 '저장 오류'로 표기한다.

## 적용 내용
1. 상태 배지는 예정(시계), 완료(체크), 기한 초과(경고)의 평면 선형 아이콘과 기존 텍스트·의미 색상을 함께 표시한다. 의미 색상 외의 장식색을 추가하지 않는다.
2. 집안일 완료 체크 아이콘을 채움형에서 선형 체크로 변경한다. 완료·취소 동작은 변경하지 않는다.
3. 홈 테마 버튼 아이콘은 시스템(밝기 설정), 라이트(해), 다크(달)로 구분한다. 접근성 설명 '테마 전환 · 현재 X'를 유지한다.
4. 오늘 집안일 0건은 '오늘 예정된 집안일 없음'으로 명시하고 0/0 진행 바의 채움 부분은 렌더링하지 않는다. 전부 완료는 '모두 완료', 일부 진행은 n%로 표시한다.
5. 구성원별 남은 작업 안내는 배정 없음/모두 완료/N개 남음을 구별한다.
6. 주간 완료 0건의 차트에는 막대 채움을 그리지 않는다.
7. 실제 작업 화면에서 남아 있던 데모 안내와 오해의 소지가 있는 오류 제목을 바로잡는다.
