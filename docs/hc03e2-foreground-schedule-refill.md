# HC-03-E2 — 전경 자동 일정 보충

- 공동 공간 미리보기 진입 후 현재 계정과 서버 확인 snapshot, 저장된 반복 규칙 및 참여자 권한을 확인하여 오늘~62일 뒤의 누락 회차만 기존 generateRemoteSchedule Callable로 보충합니다.
- 앱이 전경일 때만 실행하고 날짜 전환을 확인합니다. 계정·공간별 한 번의 진입/날짜/규칙 revision 내 동일 요청을 중복 발송하지 않으며 최대 6개 작업 호출 후 명시적 이어서 보충을 요구합니다. 오류/시간 초과 시 중단합니다.
- 기존 완료·건너뛰기·취소 회차는 이미 존재하는 자료로 취급합니다. 수정이나 복구를 자동으로 실행하지 않습니다. 오프라인, 권한 불명, 완료 미확정 요청 및 다른 수동 일정 요청 중에는 시작하지 않습니다.
- 개발 미리보기에서 자동 보충을 끄거나 재확인할 수 있습니다. 앱 종료 상태의 서버 스케줄러/전체 일괄 실행은 아직 미구현이며 비용/운영 검증 후 별도입니다.
- Kotlin 단위 테스트 및 CI를 추가합니다. 실제 기기 전경/백그라운드 전환, 복수 기기, 운영 Firebase 검증은 별도입니다. Play/Firebase 운영 배포 없음.
