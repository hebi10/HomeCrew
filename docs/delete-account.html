HomeCrew 계정 삭제 요청

앱: HomeCrew (com.hebi.homecrew) · 개발자: hebi10

앱을 설치하지 않았거나 앱을 사용할 수 없는 경우에도 이 페이지에서 Firebase 로그인 계정 삭제를 요청할 수 있습니다.

삭제 요청 방법

HomeCrew 계정 삭제 요청 이메일 보내기

이메일에 HomeCrew 계정 삭제 요청이라는 내용과 계정 확인에 필요한 Google 로그인 이메일 주소를 기재해 주세요. 비밀번호, 인증 코드, 토큰은 절대 보내지 마세요. 운영자는 계정 소유권 확인이 필요한 경우 별도로 안전한 확인 절차를 안내하며, 확인 전에는 임의의 계정을 삭제하지 않습니다.

요청 및 본인 확인 후 Firebase Authentication 사용자 계정 삭제를 처리하고 결과를 안내합니다. 이 웹 페이지에서 버튼을 누르는 것만으로 삭제가 자동 완료되지는 않습니다.

삭제 대상과 유지되는 정보

삭제 대상은 HomeCrew의 Firebase Authentication 계정 식별 및 프로필 정보입니다. Google 계정 자체는 삭제하지 않습니다. 현재 집안일과 구성원은 사용자 기기에만 보관되며 Firebase 계정에 연결되어 있지 않습니다. 운영자는 그 로컬 자료를 원격으로 삭제할 수 없습니다. 기기 내 자료는 Android 설정의 앱 데이터 삭제 또는 앱 제거로 정리할 수 있으며, 사용자가 별도로 저장한 JSON 백업 파일은 직접 삭제해야 합니다.

현재 버전에는 Firestore를 이용한 집안일 동기화가 없습니다. 향후 클라우드 데이터 처리가 추가되면 계정 삭제 범위와 절차를 변경하고 사전에 안내합니다.

앱에서 직접 삭제

앱에 접근할 수 있다면 설정 → 계정 → 계정 삭제를 이용할 수도 있습니다. 재인증이 필요한 경우 본인 Google 계정을 다시 선택한 뒤 Firebase 인증 계정을 삭제합니다.

개인정보 처리의 자세한 내용은 HomeCrew 개인정보처리방침을 참조해 주세요.
