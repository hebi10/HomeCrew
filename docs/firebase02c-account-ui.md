# HomeCrew FIREBASE-02-C — 로그인 안내·계정 관리 UI

진행 상태: 기능·화면 코드 반영, Android CI·5환경·화면 QA 검증 전. Google Play 업로드 금지.

## 범위

기존 설정 화면 안의 `계정` 영역을 보완합니다. 앱 전체 온보딩이나 홈/집안일/일정/통계 탐색 구조는 변경하지 않습니다.

- 계정 상태를 `HomeCrewAuthSession` 이벤트로 표시합니다. 로그인 버튼 반환값을 실제 로그인 상태로 오인하지 않습니다.
- 상태: 복원 중(진행 안내), 로그인 없이 사용(선택형 Google 로그인), 로그인 진행 중(중복 입력 방지), 로그인 완료(이름·이메일), 취소·계정 없음·네트워크·설정·자격 증명·기타 오류(안내·재시도).
- 로그인 완료 사용자의 이름/이메일을 인증 상태 모델에서 안전하게 보여 줍니다. 값이 누락되면 `정보 없음`으로 표시합니다. Firebase UID나 토큰은 UI에 표시하지 않습니다.
- 계정 인증과 기존 로컬 구성원 프로필/데이터는 분리합니다. Google 로그인은 Firestore 동기화·집안일 공유가 아니며 그 사실을 계정 영역에 표시합니다.
- 로컬 사용 기능은 계속 제공하고 Google 로그인을 강제하지 않습니다. 로컬 전용 빌드에 없는 Google 로그인은 임의로 노출하지 않습니다.
- 로그아웃, 계정 삭제, 계정 전환, Firebase 사용자-로컬 구성원 매핑 및 동기화는 이 단계에서 추가하지 않습니다. FIREBASE-02-D 및 FIREBASE-03~05 후속으로 관리합니다.

## 화면 구조

1. 설정 > 계정: Google 인증 기능이 있는 빌드에서 테마 설정 다음에 노출. 별도의 메뉴/탭이나 비동기 네트워크 자동 요청을 추가하지 않습니다.
2. 상태 제목 및 안내: 현재 인증 상태를 짧은 한국어로 표기합니다.
3. 인증 정보: Google 로그인 완료 시 이름/이메일. 빈 값도 정확히 표시하고 UID는 숨깁니다.
4. 선택형 Google 로그인: 로컬 사용 상태에서만 활성. 버튼 최소 높이는 기존 HomeCrew `touchTarget`을 따릅니다.
5. 피드백: 취소/계정 없음은 안내색, 실제 실패는 오류색. 스크린리더에서는 `LiveRegionMode.Polite`로 상태 변경을 알립니다.
6. 보관 안내: 로그인만으로 집안일/구성원/완료 이력이 원격 공유되지 않는다는 점을 알립니다.

## 디자인 기준

기존 HomeCrew 공통 라이트·다크 토큰과 Material3 타이포그래피 유지. 화이트/그레이·차콜/블랙, 장식형 그림자/그라데이션/인위적 입체 효과 없음. 기존 설정 `LazyColumn` 스크롤·상태바 인셋·큰 글꼴·태블릿 정보 흐름 보존. 계정 영역만 변경, 타 화면 UI 비변경.

## 구현·테스트

- `HomeCrewAccountUiState.kt`: Firebase 세션 + 로그인 작업 결과를 UI 상태로 변환하는 순수 함수.
- `HomeCrewGoogleAccountSetting.kt`: Firebase 이벤트 구독 유지, 계정 표시용 단순 Compose 컴포넌트 분리, 라이트/다크 프리뷰.
- `HomeCrewSettingsScreen.kt`: 기존 설정의 계정 섹션 배치 조정.
- JVM 테스트: 인증 상태·중복 요청 방지·사용자 정보 누락·취소/오류·UID 비노출·로그인 결과와 세션의 분리.
- Android 캡처: OAuth 리소스 존재 시 실제 설정의 계정 섹션 화면 캡처, 비로그인/로그인 상태 검증.
- 전체 QA: Android API29/35/36, API35 태블릿·160% 글꼴, 라이트/다크, 기본 집안일 CRUD/Room 데이터 회귀.
