# HC-03-A — 공동 집안일 조회 및 상태 모델

## 범위
- FIREBASE-05 #49를 기반으로 공통(RemoteHouseholdReadGateway) 인터페이스와 조회 전용 Compose 다이얼로그를 작성합니다.
- 현재 집의 chores/occurrences 및 집 문서의 실시간 메타데이터를 구독합니다. 서버 확인 상태가 아닌 캐시, 쓰기 대기, 연결 오류, 권한 상실 시 조회 화면에서 기존 데이터를 제거합니다. UID에 고정된 게이트웨이 사용이 가능하며 계정/집 변경 시 Compose 구독을 새로 시작합니다.
- 한국 시간 기준 선택 날짜의 회차, 담당 여부, 난이도, 완료/건너뛰기 상태, 아직 수신되지 않은 정의 안내를 표시합니다. 로컬 Room 및 기존 네 탭은 변경하지 않습니다.
- 단위 테스트는 서버 확인/캐시 상태 전환, 권한 오류, 날짜·배정·완료·건너뛰기 및 누락 데이터 처리 검증을 수행합니다.
