# HC-03-A — 공동 집안일 조회 및 상태 모델

## 범위
- FIREBASE-05 #49를 기반으로 공통(RemoteHouseholdReadGateway) 인터페이스와 조회 전용 Compose 다이얼로그를 작성합니다.
- 현재 집의 chores/occurrences 및 집 문서의 실시간 메타데이터를 구독합니다. 서버 확인 상태가 아닌 캐시, 쓰기 대기, 연결 오류, 권한 상실 시 조회 화면에서 기존 데이터를 제거합니다. UID에 고정된 게이트웨이 사용이 가능하며 계정/집 변경 시 Compose 구독을 새로 시작합니다.
- 한국 시간 기준 선택 날짜의 회차, 담당 여부, 난이도, 완료/건너뛰기 상태, 아직 수신되지 않은 정의 안내를 표시합니다. 로컬 Room 및 기존 네 탭은 변경하지 않습니다.
- 단위 테스트는 서버 확인/캐시 상태 전환, 권한 오류, 날짜·배정·완료·건너뛰기 및 누락 데이터 처리 검증을 수행합니다.

## 선행 및 후속
- #49 기반의 별도 Draft입니다. #58 병합 main을 반영하여 개발 미리보기의 공동 공간 선택 화면에서 계정 고정 조회 게이트웨이를 연결했습니다. 정식 빌드 및 운영 프로젝트에는 노출하지 않습니다. #49 병합 후 새 main 기준 최종 검증이 필요합니다.
- 에뮬레이터 통합 테스트에 공동 집안일 생성, 회차 중복 방지, 완료/취소 및 동일 요청 재생, 오래된 revision 충돌, 구성원 제거 후 읽기/쓰기 차단을 추가했습니다.
- HC-03-B에서는 서버 기준 완료/취소 UI, 안정적인 요청 UUID 재시도, 충돌·오프라인 쓰기 정책을 연결합니다.
- 두 계정/두 기기 실시간 상태·권한 박탈/재접속·오프라인 및 화면 검증과 HC-04/05/06은 별도 작업입니다.
- 운영 Firebase/Play 배포 및 사용자 자료 이전 금지.

## HC-03-B — 서버 확인 기반 완료 및 취소
- #49 병합 main을 기준으로 #59를 재통합합니다. 개발 미리보기에서만 완료/취소를 제공합니다.
- 현재 서버 확인 snapshot의 회차 revision과 명시적인 목표 완료 상태를 전송하며, 건너뛴 회차와 누락된 원본·캐시 상태에서는 변경을 차단합니다.
- 쓰기 중 중복 클릭을 차단하고 낙관적 완료 표시 없이 Callable 응답 및 최신 서버 snapshot을 확인합니다. 응답 유실/시간 초과는 미확정으로 표시합니다. 열린 화면 안에서 동일 requestId, revision, 목표값을 사용한 명시적 재시도를 지원합니다. 충돌/권한 거부는 재구독하여 최신 상태를 확인합니다.
- 오프라인에서 새로운 쓰기나 자동 전송을 하지 않습니다. 앱 재시작까지 보존하는 영속 오프라인 큐, 사용자 선택에 따른 재연결 동기화, 반복/배정 서버 엔진 및 두 실기기 UI 검증은 별도 작업입니다.
- Kotlin 상태 전이 테스트와 Firebase 에뮬레이터에서 동일 revision을 이용한 실제 동시 쓰기 경쟁(한 요청 성공·다른 요청 충돌), 중복 요청 재생, 권한 박탈 검증을 추가합니다.
- 운영 프로젝트 및 release 활성화 금지, 기존 Room 및 Play 변경 없음.
