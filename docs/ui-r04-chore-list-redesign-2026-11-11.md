# UI-R04 — 집안일 목록 리디자인

기준일: 2026-11-11 / `main` b1e9dd83461b2e0c95e4d91c35e83e19856a141c

원본: 002_HomeCrew_공통디자인_및_화면별_상세기획_v1.0

## 문제
- 기존 집안일 화면은 `ChoreDefinition` (작업 규칙 원본) 목록을 보여 주지만, 옆의 예정·완료 배지는 오늘의 `DemoChore` 회차를 기준으로 표시합니다. 원본과 회차가 구분되지 않았습니다.
- 기존 '기한 초과' 필터도 오늘 회차 상태만 검사하므로 과거 날짜에 남은 미완료 회차를 검색할 수 없었습니다.
- 검색 다음에 카테고리·상태 필터 줄이 계속 쌓여 실제 작업 목록의 노출이 늦었고 구성원·반복·정렬 옵션은 없었습니다.

## 구현
1. 상단에는 집안일 이름 검색과 주요 상태 칩(전체·예정·완료·기한 초과)을 배치합니다.
2. 접을 수 있는 '필터 및 정렬'에 카테고리, 구성원, 반복 여부(전체/반복/일회성), 정렬(이름순/시간순/업무량순)을 배치합니다. 필터와 선택값은 탭 이동 후에도 보존하며, 필터 초기화 시 조건만 지웁니다.
3. 상단에 '표시 N개 · 전체 N개 등록된 작업 원본'과 상태 기준을 설명합니다.
4. 작업 원본을 높이 최소 64dp의 한결 낮은 컴팩트 항목으로 표시하고 제목/오늘 상태/카테고리/반복/담당/예정 시간/업무량을 읽기 쉬운 순서로 제공합니다.
5. 회차 상태 기준:
   - '예정' = 오늘 예정된 회차 중 미완료.
   - '완료' = 오늘 회차 완료.
   - '기한 초과' = 오늘 이전 날짜의 미완료 회차가 하나 이상 있는 작업 원본.
   - 오늘 회차가 없으면 '오늘 회차 없음' 안내. 이후 생성된 가까운 회차가 있으면 다음 날짜 표시.
   - 지난 미완료 회차 수를 별도로 표시. '기한 초과' 필터 선택에서 행 클릭 시 최신 과거 미완료 회차의 상세를 엽니다.
6. 구성원 필터는 고정 담당뿐 아니라 순번제/업무량 균형 분담의 참여자 목록을 기준으로 적용합니다. 오늘 회차의 현재 담당자가 다른 경우에도 해당 참여자의 작업이 누락되지 않도록 합니다.
7. 아직 원본이 없는 상태에서는 집안일 추가 버튼을 제공하고, 필터 결과가 없는 상태에서는 초기화를 제공합니다.
8. 기존 상세/등록/완료/취소와 Room CRUD를 연결하며 모델 변경·마이그레이션 없이 로컬 스냅샷으로 계산합니다.

## 변경 보호
- `ChoreDefinition`, `DemoChore`, Room DB, Repository, ViewModel, 반복 계산/배정, 알림/권한, Play 배포 워크플로는 수정하지 않습니다.
- 기존 1-A 흑백/회색 토큰과 작은 라운드, 20dp 화면 패딩, 48dp 터치, 64dp 행 최소 높이를 유지합니다. 그림자·그라데이션·장식 애니메이션은 추가하지 않습니다.
- PR #12 (2-A-03) 미병합 상태이므로 백업/건너뛰기 로직은 본 PR에 포함하지 않습니다.
