# HC-03-C2 — 서버 반복 일정 및 고정·순번 배정 기반

- 기존 로컬 ChoreEditing.kt와 동일한 날짜 규칙을 서버 순수 함수로 구현: 반복 없음, 매일, 매주(요일), 격주(월요일 기준), 매월(월말 보정), 사용자 지정 간격.
- 서버 Callable configureRemoteSchedule에서 인증·멤버십·담당자 UID·revision을 검증하고 반복 규칙을 보관합니다. generateRemoteSchedule은 최대 63일의 요청 구간에서 한국 시간 기준 허용 기간 내 누락 회차만 트랜잭션으로 생성합니다.
- 고정/순번제 배정은 기준일에서 결정적으로 계산하며 요청 구간·기기·재시도에 따라 달라지지 않습니다. 기존 회차 ID와 완료·건너뛰기 기록을 변경하거나 삭제하지 않습니다. 단일 ensureRemoteOccurrence 호출에서도 설정된 반복 규칙을 벗어난 신규 회차 생성을 차단합니다.
- 기존 일정의 미래 회차 재조정 정책, 전체 업무량 균형 배정(현재 명시적 거부), Android 반복 설정/생성 버튼 연결, 예약 자동 생성, 과거 데이터 이전은 후속입니다. 변경된 규칙과 기존 회차를 자동으로 합치거나 덮어쓰지 않습니다.
- Node 단위 테스트(6종 날짜 규칙·월말·격주·순번·잘못된 입력) 및 전용 Auth/Firestore/Functions 에뮬레이터 통합 검증(권한·CAS·중복·기록 보존·기간 제한·탈퇴자 배정 차단)을 추가합니다.
- 운영 Functions 및 Play 배포 없음. 기존 로컬 Room과 release 미리보기 차단 유지.
