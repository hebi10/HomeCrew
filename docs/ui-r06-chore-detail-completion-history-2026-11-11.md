# UI-R06 — 집안일 상세·완료·취소·최근 기록 개선

기준: 2026-11-11, HomeCrew `main` a78bf6f531da84b7b8268e278a006fd30c20916e
기획: Google Drive 011_HomeCrew_디자인시안_실제화면_차이분석_단계별개선계획_2026-11-11 (HC-11)
공통 디자인: Google Drive 002_HomeCrew_공통디자인_및_화면별_상세기획_v1.0

## 문제 및 개선
- 기존 상세의 상태·완료 버튼이 규칙/이력 카드와 비슷한 시각적 무게로 표시되어 핵심 행동이 두드러지지 않았습니다.
- '가까운 예정 회차'가 이미 완료된 회차도 포함하고, 최근 완료 기록에는 실제 완료자가 아니라 작업 원본의 예정 담당자를 표시했습니다.
- 완료 이력을 보고도 특정 과거 회차를 선택하여 완료 취소할 수 없는 구조였습니다.
- Room에는 이미 `ChoreOccurrenceEntity.completedBy`와 `completedAtEpochMillis`가 저장되어 있으나 UI용 `DemoChore`에는 값이 전달되지 않았습니다.

## 구현
1. 선택 회차의 상태·날짜·예정 시각·예정 담당자와 완료/취소 버튼을 화면 최상단에 집중했습니다.
   - 미완료 회차: 주요 버튼 '이 회차 완료 처리', 처리되면 현재 선택한 구성원을 실제 완료자로 기록.
   - 완료 회차: 보조 버튼 '이 회차 완료 취소', 해당 회차의 완료자 및 완료 시각도 함께 해제.
   - 해당 선택 회차에만 상태를 변경하며 다른 회차나 반복 규칙은 수정하지 않습니다.
2. Room에 존재하는 완료자/완료 시각을 UI 모델로 노출합니다. DB 스키마·DAO·Room 마이그레이션은 변경하지 않습니다.
   - 실제 완료자/시간이 없는 과거·데모 완료 기록은 '기록 없음'으로 구분합니다.
   - 예정 담당자와 실제 완료자를 혼동하지 않도록 별도 라벨을 유지합니다.
3. 목록을 '가까운 예정 회차' (오늘 이후, 미완료), '지난 미완료 회차' (오늘 이전, 미완료), '최근 완료 기록' (완료 기록, 최신 실제 완료 시각 우선)으로 구분합니다.
   - 각 그룹의 표시 회차는 최대 3건이며 빈 상태 안내를 제공합니다.
   - 회차 행 클릭 시 그 회차를 선택하고 화면 상단의 조작 영역으로 이동합니다. 선택 상태는 상위 네비게이션의 `selectedOccurrenceId`를 통해 보존됩니다.
4. 설명, 반복·담당 규칙, 집안일 수정·삭제는 아래에 정리합니다. 삭제 전 확인 및 기록 삭제 안내는 기존 동작 그대로 유지합니다.
5. 기존 화이트/그레이·차콜 디자인 토큰, 20dp 여백·64dp 행 최소 높이·48dp 터치 기준을 유지하고 장식 애니메이션/그림자·새 의존성은 추가하지 않습니다.
