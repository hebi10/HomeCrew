# HomeCrew · 1-B-QA 화면 캡처 및 디자인 대조

## 검증 범위

- 기준 커밋: `a9c910e337e58bb6d1905041723dc8f3831daed0` (1-B main 병합)
- 기준 시안: [1-B 디자인 이미지](design/02-homecrew-main-screens.png)
- 화면: 홈, 일정, 집안일, 통계
- 환경: Android API 35 에뮬레이터(Pixel 6), 시스템 라이트 및 앱 다크

## 실행

- [HomeCrew screen QA workflow](https://github.com/hebi10/HomeCrew/actions/workflows/screenshot-qa.yml)
- `MainScreensScreenshotTest`는 실제 Android 화면을 실행하고, 네 하단 탭을 이동한 뒤 PNG를 저장합니다.
- 홈 완료 버튼 1회 조작 후 홈과 통계 재캡처, 앱 다크 모드 전환 후 홈 재캡처를 추가합니다.
- 아티팩트: `homecrew-1b-screen-qa` (01 홈 / 02 일정 / 03 집안일 / 04 통계 / 05 완료 후 홈 / 06 완료 후 통계 / 07 다크 홈)
- 스크린샷은 CI 워크플로가 실제로 성공하고 아티팩트가 생성된 뒤에만 실기기 검증으로 인정합니다.

## 기획 시안 대비 코드 기준 사전 검토 (화면 시각 검증과 별개)

| 화면 | 사전 확인 | 실제 캡처에서 검증할 항목 |
|---|---|---|
| 홈 | 시안의 알림/설정 아이콘 대신 테마/디자인 갤러리 아이콘을 사용 | 진행률 카드, 작업 밀도, 상태 텍스트, 하단 탐색 간격 |
| 일정 | 월·주·일 탭과 날짜 이동 로직 존재 | 월간 날짜 크기, 작은 화면, 터치 선택, 목록 가독성 |
| 집안일 | 검색·카테고리·상태 필터와 읽기 전용 상세 존재 | 목록 높이, 긴 제목, 필터 줄바꿈, 공백 |
| 통계 | 완료율·집계·막대 그래프 구현 | 지표 배치, 바 높이, 수치 레이블, 색상 대비 |

## 수동 QA 체크리스트

- [ ] 실제 캡처 4장과 1-B 이미지 육안 비교
- [ ] 홈 완료 변경이 통계 수치에 즉시 반영되는지 확인
- [ ] 일정 월/주/일과 오늘 이동, 날짜 선택 확인
- [ ] 집안일 검색·카테고리·상태 필터 확인
- [ ] 폰트 1.3배/작은 화면/가로 전환 확인
- [ ] 다크 화면의 텍스트와 상태 대비 확인
- [ ] 발견한 차이를 P0(기능/가림), P1(가독성), P2(장식)으로 분류

> 주의: 1-B 시안의 일러스트·아이콘·그래프 스타일은 실제 Compose와 동일하다고 가정하지 않습니다. 이미지 아티팩트를 확인하지 않고 QA 완료로 표기하지 않습니다.
