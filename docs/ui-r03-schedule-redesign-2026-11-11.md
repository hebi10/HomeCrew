# UI-R03 — 일정 화면 리디자인

대상: HomeCrew (main 87440ac 기반) / Kotlin + Jetpack Compose / Room v1
기획: Google Drive 011_HomeCrew_디자인시안_실제화면_차이분석_단계별개선계획_2026-11-11의 HC-06

## 구현 범위
1. 기존 월·주·일 기능을 48dp 높이의 동일 폭 세그먼트 컨트롤로 배치합니다. 현재 모드를 명확하게 표시하고 접근성 설명 월 보기·주 보기·일 보기를 제공합니다.
2. 이전/다음 기간, 오늘 돌아가기와 현재 선택 날짜 상태를 유지합니다. 월말·연말·윤년 이동 계산은 기존 LocalDate 기반 로직을 공유 함수로 정리합니다.
3. 전체 및 구성원별 필터를 추가합니다. 일정 그리드/주간 스트립의 건수와 완료 개수, 선택 날짜 작업 목록은 같은 필터가 적용되어야 합니다.
4. 날짜별 상태는 0건 – / 미완료 N건 / 부분 완료 M/N / 전체 완료 완료로 표시합니다. 접근성 설명에는 총건수·완료건수를 모두 포함합니다.
5. 선택 날짜에서 집안일 추가 화면을 열고 시작일을 그 날짜로 미리 입력합니다. 구성원 필터가 활성화되어 있으면 해당 구성원을 기본 담당자로 전달합니다.
6. 기존 작업 완료/취소, 상세 이동, 라이트·다크, 4탭 및 Room 저장을 유지합니다.

## 일정 생성 지원 범위
현재 Room v1의 previewDraftInstances는 today부터 today+62일의 회차만 만듭니다. 선택 날짜가 이 범위를 벗어나면 집안일을 추가해도 회차가 생성되지 않을 수 있으므로, 과거/63일 이후에는 날짜 추가 버튼을 비활성화하고 이유를 안내합니다. 반복 회차 자동 갱신 및 장기 날짜 생성 범위는 미병합 PR #12 (2-A-03) 검증 후 별도 확장합니다.

## 변경 보호

- HomeCrewMainScreens에서 openAdd 경로에 날짜/담당을 전달. PR #12와 기능 분리 유지. 향후 PR #12 리베이스 시 동일 파일 충돌 확인 필요.
