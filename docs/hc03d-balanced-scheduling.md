# HC-03-D1 — 업무량 균형 서버 배정

- 공동 공간의 이미 배정된 주간 업무량(월요일~일요일)을 합산하고, 새 회차를 생성할 때 설정한 참여자 중 가장 낮은 부담 점수의 구성원에게 배정합니다. 동률이면 설정된 참여자 순서 우선, 새로운 날짜는 오름차순 처리합니다.
- 로컬의 7일 기준 가중치 개념을 서버의 명시적인 달력 주 단위로 적용합니다. 생성 순서와 기존 배정에 따라 새 회차의 담당자가 달라질 수 있으며 기존 기록은 재배정하지 않습니다.
- 기존 완료/건너뛴 회차를 포함한 배정 업무량을 계산합니다(완료 실적 순위와는 별개). 신규 회차는 당시 업무량 점수를 함께 기록하며, 기존 회차는 원본 정의 점수를 참조합니다. 누락/비정상 자료나 지나치게 큰 ledger는 근사하지 않고 안전하게 실패합니다.
- 단일·일괄 회차 생성 모두 동일한 household 문서의 트랜잭션 직렬화 경계를 사용하여 다른 집안일 동시 생성 및 멤버십 변경과 경쟁할 때에도 기존 배정을 유지합니다. 균형 배정은 모든 후보의 현재 권한을 검증합니다.
- Node 단위 테스트 및 demo Firebase 동시 생성/탈퇴 후 배정 차단 통합 테스트를 추가합니다.
- HC-03-D2 Android 설정/회차 생성 UI 및 미래 회차 변경·자동 생성·과거 이관·실기기 검증은 별도입니다. 운영 Firebase/Play 변경 없음.
