## 디자인 원칙과 판정
- 1-A 디자인 토큰은 이미 설계와 일치: 라이트 #FAFAFA/#FFFFFF/#171717, 다크 #121212/#1E1E1E/#F5F5F5.
- 타입 24/18/16/14/12sp, 좌우 20dp, 버튼 52dp, 터치 48dp, 작업 행 64dp 기준 기존 값 유지.
- 색상·일러스트·과도한 라운드/그림자 추가 금지. 상태 색상은 성공/주의/오류에만 사용.
- 따라서 디자인 토큰 자체의 불필요한 값 변경 없이 기존 컴포넌트를 보존.

## 작업
1. 최초 사용/집안일 템플릿에서 '시연 데이터·실행 내역 메모리 초기화' 안내를 실제 Room 영구 저장 사실로 정정.
2. 홈·일정·집안일·통계·상세에서 매번 반복되는 로컬 저장 안내 패널 제거. 저장/삭제의 구체적 영향 고지는 유지. 최초 안내에서 로컬 저장·다기기 동기화 미지원 고지.
3. 홈의 개발용 '1-A 디자인 시스템 보기' 버튼과 앱 런타임 진입 분기 제거. `HomeCrewDesignSystemGallery.kt` 및 Compose Preview는 삭제하지 않고 개발자용으로 보존. 현재 홈의 테마 전환은 유지; 정식 설정 화면은 UI-R08에서 별도 설계.
4. 필요하지 않은 구형 임시 상세 대화상자 설명 수정.
5. 기존 메인 4탭·집안일 CRUD·담당·반복·Room 영속화·완료/취소 코드에는 손대지 않음.
6. Android QA에 최초 설정/템플릿의 구형 문구 부재, 홈 개발 메뉴/중복 안내 부재 검사 추가.
