# HC-03-E1 — 미래 회차 안전 조정

- 반복 규칙 저장 및 누락 회차 생성과 별도로, 소유자가 내일~오늘+62일 범위의 기존 회차 변경 미리보기를 보고 직접 반영합니다. 오늘·과거·완료·건너뛰기·완료 취소 등 일반 변경 이력은 보호합니다.
- 변경할 수 있는 회차는 신규 revision=1 또는 마지막 변경이 이 기능 자체인 회차로 제한합니다. 규칙에 맞지 않는 회차는 삭제 대신 scheduleCancelledAt으로 보존하며, 고정/순번 규칙에서 다시 대상이 되면 복구 또는 담당자 변경을 허용합니다. 균형 배정의 기존 회차 재배정/복구는 추정하지 않고 보류합니다.
- 미리보기 해시는 계정·공간·규칙 revision·서버 날짜·정확한 변경 항목에 결합합니다. 서버에서 다시 계산하고 불일치 시 아무 변경도 수행하지 않습니다. 동일 확인 재시도에는 작업 영수증을 반환합니다.
- 취소 회차는 완료 요청과 균형 부하 합산에서 제외합니다. 기존 회차 ID 및 기록은 유지합니다.
- Node 단위 및 demo Firebase 통합 테스트에 미리보기 무변경, 권한, 동시 완료 충돌, 이력 보호, 재시도와 복구를 포함합니다.
- 자동 백그라운드 일정 보충, 균형 회차 재배정/복구, 물리 기기 UI 검증은 별도입니다. 운영 Firebase/Play 변경 없음.
