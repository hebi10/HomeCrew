# HC-06-A — 계정 삭제 전 데이터 범위 확인 및 인증 단독 삭제 차단

- 현재 공동 공간 소유권/멤버십을 사용자 인덱스와 독립적으로 조회하여 누락·불일치 인덱스를 발견합니다. 최대 50개 공간; 초과나 잘못된 권한 기록은 검토 실패로 처리합니다. 다른 계정의 UID를 입력해도 인증 UID 기준 조회만 수행합니다.
- 표시명, 이전 세션, 초대, 집안일 담당/생성/반복 배정, 회차/완료자, 작업 기록 및 계정/초대 제한 관련 참조의 존재 여부를 읽기 전용으로 조회합니다. 기존에 탈퇴한 계정의 과거 참조도 확인합니다. 내포된 작업 자료/백업 등 전체 데이터 인벤토리나 완전한 삭제 증명은 아닙니다.
- 공동 공간 개발 미리보기 설정에서는 UI와 Firebase 인증 공급자 양쪽에서 Auth-only 삭제를 차단하고 계정 삭제 사전 확인 화면을 제공합니다. 미리보기 설정 오류/연결 실패/0개 공간인 경우도 삭제하지 않습니다. 기존 release 로컬 인증 계정 삭제 경로는 유지합니다(공동 공간 출시 전 반드시 안전 삭제 경로로 변경 필요).
- Firestore 컬렉션 그룹 인덱스 정의 및 demo Firebase 통합 QA를 추가합니다. 읽기 전용이며 실제 데이터/인증 계정을 수정하거나 삭제하지 않습니다.
- HC-06-B 후속: 재인증·삭제 요청/중단 복구, 소유권/탈퇴 처리, 공동 기록 익명화 및 원본 보존 범위, 서버 접근 차단/토큰 회수, 임시 자료·인덱스·초대·기기별 백업 정리, IAM/감사/만료, 웹 삭제 경로/개인정보처리방침 및 두 기기 QA. 실제 운영 계정 삭제는 위 조건 검증 후에만 연결합니다.
- 운영 Firebase/Play/Pages 배포 없음.
