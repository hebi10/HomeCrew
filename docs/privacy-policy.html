HomeCrew 개인정보처리방침

시행 예정일: 2026년 11월 14일 · 대상 앱: HomeCrew (com.hebi.homecrew)

본 방침은 Firebase Google 로그인 기능이 포함된 향후 테스트 버전의 개인정보 처리 내용을 설명합니다. 기존에 배포된 버전과 다를 수 있으며, 해당 기능을 실제 제공하기 전에 본 방침의 게시 여부를 확인합니다.

1. 기기에서 관리하는 정보

집 이름, 구성원 이름, 기본 구성원, 집안일의 이름·설명·카테고리·난이도·담당자·반복 규칙·예정 회차·완료 및 건너뛰기 기록은 사용자의 기기 안에 저장합니다. 구성원 이름은 Firebase 로그인 계정과 자동으로 연결되지 않습니다. 앱 내 기능으로 사용자가 선택한 JSON 백업 파일은 암호화되지 않으며, 사용자가 선택한 저장 위치에 보관됩니다.

2. 선택적 Google 로그인과 서버 처리

사용자가 Google 로그인을 선택하면 Google 및 Firebase Authentication에서 계정 확인을 위해 인증 정보가 처리됩니다. Firebase는 계정 식별자(UID), Google 프로필의 표시 이름·이메일, 인증 상태 등 계정 관리에 필요한 정보를 보유할 수 있습니다. 앱은 OAuth 토큰을 직접 기기의 별도 파일이나 집안일 데이터베이스에 저장하지 않습니다. 현재 이 버전에는 가족 초대, Firestore 집안일 공유, 원격 집안일 동기화, 광고·분석·결제 기능이 없습니다.

3. 이용 목적과 제공

로그인 정보는 사용자가 선택한 Firebase 인증 기능 및 계정 상태 표시를 위해 사용합니다. 집안일과 구성원 정보는 기기에서 관리하며 로그인만으로 다른 스마트폰이나 개발자 서버로 전송하지 않습니다. Google 및 Firebase의 인증 관련 데이터 처리에는 해당 제공업체의 서비스·개인정보처리 기준이 적용됩니다.

4. 보관 및 삭제

Firebase 로그인 계정은 앱 설정에서 삭제를 요청할 수 있습니다. 보안상 최근 로그인 확인이 필요하면 같은 Google 계정으로 다시 인증합니다. Firebase 계정 삭제가 성공하면 해당 Firebase Authentication 사용자 레코드가 삭제되며, Google 계정 자체는 삭제되지 않습니다. 앱에서 로그아웃해도 Firebase 계정은 유지됩니다.

Firebase 인증 계정과 기기 내 로컬 집안일은 별도로 관리됩니다. 계정을 삭제하거나 로그아웃해도 집 이름·구성원·Room 데이터 및 완료 기록은 삭제되지 않습니다. 이 로컬 자료는 Android 설정에서 앱 데이터 삭제 또는 앱 제거 시 삭제될 수 있습니다. 사용자가 외부 위치에 저장한 JSON 백업 파일은 별도로 삭제해야 합니다. 향후 Firestore 동기화 도입 시 계정 연관 데이터 삭제 범위와 절차를 추가로 공지합니다.

앱을 설치하지 않고 계정 삭제를 요청하려면 HomeCrew 계정 삭제 요청 안내를 이용해 주세요. 웹 요청은 운영자가 본인 확인 후 Firebase Authentication 계정을 삭제하는 절차이며 자동 삭제 완료를 의미하지 않습니다.

5. 접근 권한과 보호

현재 로컬 집안일 기능을 이용하기 위해 연락처, 위치, 카메라, 마이크, 갤러리 접근을 요청하지 않습니다. 기기에 저장하는 정보는 Android 앱 전용 저장소에서 관리합니다. 기기 분실과 외부 저장 백업 파일의 무단 공유를 방지하기 위해 기기 잠금 및 백업 보관에 유의해 주세요.

6. 문의 및 변경

실제 서비스에 적용하는 데이터 처리 방식이 변경되는 경우 방침과 시행일을 갱신합니다.
