# HomeCrew · 1-D 집안일 등록·반복·담당·상세 구현

> 범위: HC-08 집안일 등록·수정, HC-09 반복 설정, HC-10 담당 방식, HC-11 상세. **실행 중 메모리 시연 기능**으로 구현하며 Room/Firebase 영속 저장은 2-A 이후 연결합니다.

## 기존 화면 연결
- 홈 '+ 집안일 추가'/집안일 탭 '+' → HC-08 새 집안일.
- 홈·일정 회차 행, 집안일 원본 목록 행 → HC-11 상세.
- 상세 '집안일 수정' → 기존 정의로 HC-08. 시스템 뒤로 가기 지원.
- HC-08 반복/담당 요약 → HC-09/10 하위 화면. 적용 시 폼으로 복귀.
- HC-11 회차 완료·취소 → 홈/일정/통계 실시간 반영. 삭제는 확인 다이얼로그.

## 화면별 항목
| 화면 | 주요 내용 | 동작 |
|---|---|---|
| HC-08 | 이름(필수 40자), 카테고리 6종, 설명 300자, 업무량 1~5점, 시작일/시간, 반복·담당 요약, 다음 3회 | 입력 검증·등록·수정·폐기 확인 |

| HC-10 | 고정 1인, 순번제, 업무량 균형 | 참여자 선택·난이도 가중 배정 미리보기 |
| HC-11 | 현재 회차·담당·예정 시간·다음 회차·최근 완료 기록 | 회차 완료 취소·정의 편집·삭제 확인 |

## 반복·분담 규칙
- 신규 항목은 오늘부터 62일 범위의 예정 회차를 실행 중 데이터로 생성합니다. 폼의 다음 3회 미리보기는 370일 범위에서 계산합니다.
- 월말 반복은 31일이 없는 달에 그 달 마지막 날로 조정하고, 윤년에는 2월 29일을 적용합니다.
- 격주는 시작 주를 기준으로 사용자가 고른 요일에 2주마다 반복합니다.
- 고정 담당 1명, 순번제는 구성원 목록 순서, 균형 모드는 기존 예정 업무량을 초기값으로 사용한 난이도 점수 최소 배정입니다.
- 정의 수정 시 기존 완료 회차와 오늘 이전의 회차는 유지하고, 예정 미완료 회차를 새 규칙으로 재계산합니다. 이번만/이번 이후 선택은 2-A에서 이력 모델 구현 후 제공합니다.
- 삭제는 해당 정의의 모든 시연 회차·완료 기록을 제거하므로 명확히 확인받습니다.

## 디자인과 데이터 경계
- 기존 1-A 블랙/그레이 테마·타이포그래피·간격(좌우 20dp)·버튼 높이 52dp 재사용.
- 집/구성원/템플릿의 1-C 초기 설정은 기존 SharedPreferences에 남지만, 1-D의 추가·수정·완료·삭제는 실행 중 시연 상태로 앱 재시작 시 초기화됩니다.
- Firebase 로그인·초대·공유, Room, 로컬 알림/푸시, Play 배포는 포함하지 않았습니다.
